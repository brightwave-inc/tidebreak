# The baseline Python packages every exec backend guarantees, as exact pins.
#
# Skill pins say what one document skill needs; this set is what any script may
# import without a skill in play, on every backend alike. It is baked into the
# documents sandbox image (the generator reads this file, so the pins are
# top-level entries of the hash-checked closure in
# crates/tidebreak-sandbox-agent/documents-requirements.txt) and seeded into the
# local backend's offline shared package cache alongside the per-skill pin sets.
#
# Changing a pin here means regenerating the image closure in lockstep:
#   python3 scripts/generate-documents-requirements.py
# scripts/sandbox-image-pins.test.mjs fails when the two drift apart.
#
# The versions are the newest each backend can carry in common. The local
# sandbox supports CPython 3.11 and later, while the documents image uses
# CPython 3.11. The generator resolves this set for every supported local
# runtime target and fails regeneration when a pin cannot install on any of
# them.

pillow==12.3.0
